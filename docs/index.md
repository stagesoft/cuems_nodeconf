# cuems-nodeconf
FormitGo nodes autodiscovery library for the cuems system.

It handles the discovery and configuration of nodes in the cuems system network.

[![PyPI - Version](https://img.shields.io/pypi/v/cuemsnodeconf.svg)](https://pypi.org/project/cuemsnodeconf)
[![PyPI - Python Version](https://img.shields.io/pypi/pyversions/cuemsnodeconf.svg)](https://pypi.org/project/cuemsnodeconf)


## Installation

```console
pip install cuemsnodeconf
```
